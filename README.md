# ZÉPHYR – Site Web Officiel

Site web vitrine de ZÉPHYR, une entreprise fictive masi la suite d'une invention faite dans le cadre des olympiade de science de l'ingénieur 2025. Au lycée Léonard de Vincin une éolienne hybride Savonius-Darrieus destinées aux particuliers.  
Ce projet a été réalisé dans le cadre de la SAÉ 1.2 – BUT Informatique (S1).

##  Objectifs du Projet

- Concevoir un site web responsive, moderne et accessible
- Mettre en œuvre de bonnes pratiques de développement front-end (HTML5, CSS3, JavaScript vanilla)
- Justifier les choix techniques, notamment en JavaScript
- Intégrer une démarche éco-responsable (RGESN)
- Produire un code simple, lisible, maintenable, proche des attentes du monde professionnel

##  Technologies Utilisées

- **HTML5** : Balises sémantiques, validation W3C, accessibilité
- **CSS3** : Flexbox, Grid, Media Queries, variables CSS, animations
- **JavaScript** : Vanilla JS (pas de framework), interactions UX

##  Fonctionnalités Implémentées

- **Responsive Design** : Adaptation desktop, tablette et mobile
- **Mode Éco-Responsable** : Réduction des animations et ressources (RGESN)
- **Accessibilité** : Conformité RGAA en cours, navigation clavier, aria-labels
- **Formulaire de Contact** : Validation côté client, envoi simulé
- **FAQ Interactive** : Accordéon en JavaScript
- **CV Imprimables** : Styles dédiés via `print.css`
- **Plan du Site** : Arborescence complète avec liens
- **Navigation** : Menu burger responsive, boutons d'action

##  Validation et Conformité

- **HTML** : Validé via [W3C Validator](https://validator.w3.org/)
- **CSS** : Validé via [W3C CSS Validator](https://jigsaw.w3.org/css-validator/)
- **Accessibilité** : Test avec [Wave](https://wave.webaim.org/)
- **RGAA** : Audit avec [Ara](https://ara.numerique.gouv.fr/) (bonus)
